# 隐私声明 · 界面取证镜（pattern-lens）

> 适用版本：扩展 `manifest.json` 的 `version`（当前 `0.1.0`）。规则包版本见 `rules/manifest.json` 的 `ruleset_version`。
> 本声明描述的是**扩展本身**的行为；本仓库是源码仓库，不含任何服务端。

## 一句话

**零采集、零上传、零遥测、零远程代码。** 扩展只读你**点击时**那一页的渲染后 DOM，在本机算出结果，
结果只落在本机浏览器的 `chrome.storage` 里，**从不离开这台设备**。

## 1. 我们申请了哪些权限、用来做什么

权限白名单是**代码里单点定义**的（`tools/permissions-whitelist.mjs`），并由 `tests/manifest-permissions.test.mjs`
逐项断言 `manifest.json` 与之一致。当前申请**恰好五项**：

| 权限 | 为什么需要 | 不做的事 |
| --- | --- | --- |
| `activeTab` | 你**点击扩展图标**时，才获得**当前这一个标签页**的临时访问权，用于注入扫描器 | 不在后台常驻读取任何页面 |
| `scripting` | 按需把扫描器注入当前标签页（`chrome.scripting.executeScript`） | 不声明 `content_scripts`，**未点击前零注入** |
| `sidePanel` | 打开扩展的侧边栏取证台界面 | 不读取侧边栏以外的浏览器 UI |
| `storage` | 把设置存 `storage.local`、把扫描结果存 `storage.session`（都在本机） | 不上传到任何服务器 |
| `contextMenus` | 右键菜单"用界面取证镜检查本页"这一入口 | 不采集右键菜单以外的输入 |

## 2. 明确**不申请**的权限（与"不采集"承诺对应）

`<all_urls>`、`tabs`、`cookies`、`webRequest`、`webRequestBlocking`、`history`、`clipboardRead`、
`clipboardWrite`、`downloads`、`management`、`proxy`、`debugger` —— 一个都不申请。
`host_permissions` 为**空**；`web_accessible_resources` 为**空**（不把任何扩展文件暴露给网页，避免被指纹识别）。

> 判据：`tests/manifest-permissions.test.mjs` 逐项断言（多一项少一项都红）；禁用权限清单与
> `tools/permissions-whitelist.mjs` 的 `FORBIDDEN_PERMISSIONS` 单点一致。

## 3. 数据流向（全程不出本机）

```
点击扩展图标
  → service worker 读 storage.local 里的站点开关（本机）
  → 若命中黑名单：不注入，仅回传原因（本机）
  → 否则 chrome.scripting.executeScript 注入 scanner.js 到当前页
      → 采集器**只读**渲染后 DOM（文本节点 / 计算样式子集 / 几何 / 对比度）
      → 纯函数判定核心产出 findings
  → 结果经 runtime 消息回传给 service worker
  → 落 chrome.storage.session（本机；浏览器关闭即清空）
  → 侧边栏读取并展示；导出为本地文件（Blob + <a download>）
```

**链路上没有任何网络 API**：源码与拼接产物里没有 `fetch` / `XMLHttpRequest` / `sendBeacon` / `WebSocket` /
`EventSource` / 远程 `<script>`/`<link>`，也没有 `eval` / `new Function`（MV3 硬约束：无远程代码）。
判据：`tests/zero-network.test.mjs`（运行面源码断言 + 离线动态探针）与 `tools/smoke-export.mjs`
（真实浏览器 CDP `Network` 域计数：整轮扫描 + 导出期间**远程请求 0 条**）。

## 4. 我们**不**采集什么

- 不采集页面内容：不存整页 HTML、不截图、不保存表单输入、不读取登录态 / 密码 / cookie。
- 不采集你的身份：无账号、无设备指纹、无 IP 上报（因为根本没有服务端）。
- 导出**不含**截图、不含整页 HTML、不含用户输入；只有规则名、原文片段、元素定位、严重度与规则说明。
  判据：`tests/export.test.mjs` 与 `tests/export-fields.test.mjs`（按**字段名**核红线）。

## 5. 存了什么、存在哪、存多久

| 数据 | 存储 | 生命周期 |
| --- | --- | --- |
| 设置（站点黑白名单、规则开关） | `chrome.storage.local` | 你手动清除前一直保留（本机） |
| 最近一次扫描结果（`LastScan`） | `chrome.storage.session` | 浏览器会话结束即清空 |
| 同站点扫描历史（`ScanHistory`，上限 20 条） | `chrome.storage.session` | 浏览器会话结束即清空 |
| 导出的 `.md` / `.json` 文件 | 你选择的下载目录 | 由你自行管理 |

> 口径：`storage.session` 在浏览器重启后会被清空——**本项目只验"扩展后台被回收后恢复"，未验"浏览器重启后恢复"**
> （那是平台语义，非本项目可改）。已登记在 `plan/06` §五。

## 6. 第三方与远程代码

- 无第三方依赖：`package.json` 的 `dependencies` 与 `devDependencies` **均为空**；`git clone` 后无需 `npm install`。
- 无远程代码：规则包随扩展打包（`rules/` → 生成物 `src/lib/rules-pack.js`），不从网络拉取任何脚本或规则。
- 无 CDN、无字体外链、无埋点 SDK。

## 7. 你的控制权

- 可逐条关闭规则：设置里的规则开关 → 被禁用的规则不参与扫描、也不出现在导出。
- 可整站停用：站点黑名单命中 → 该站点不注入，界面明示"该站点已停用"。
- 可随时清除：卸载扩展即删除 `storage.local`；关闭浏览器即清空 `storage.session`。

## 8. 免责

本扩展产出的是**可疑模式（待核对）**的启发式取证结果，每条附规则说明与原文片段，供人工复核；
**不构成法律意见或事实认定**。详见仓库根目录 `README.md` 的"局限披露"。
