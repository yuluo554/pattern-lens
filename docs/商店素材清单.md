## 2. 商店详细描述（草案，供提交时粘贴）

**名称**：界面取证镜（pattern-lens）

**一句话**：点一下图标，侧边栏列出当前页所有**可疑模式（待核对）**——每条给规则名、原文片段、元素定位、严重度，
页面上用编号徽标高亮取证，一键导出证据包。

**它做什么**：

- 只读**渲染后**的页面 DOM，逐条找出符合内置规则的可疑界面模式（预勾选、隐藏关闭、倒计时施压、假稀缺、
  确认羞辱、锚定折扣、默认加购、挽留弹窗、订阅陷阱、隐藏费用、强制注册、暗色关闭 共 12 条）；
- 每条结论都附**规则说明 + 原文片段 + 元素定位 + 严重度**，供人工复核；
- 页面上用编号徽标高亮对应位置，侧边栏条目与徽标**双向联动**；
- 一键导出 Markdown / JSON 证据包（全本地）。

**它不做什么**：

- ❌ 不给"暗黑模式分数""欺诈指数"——**做取证，不做打分**；
- ❌ 不自动点击、不代你取消订阅、不自动填表；
- ❌ 不截图、不存整页 HTML、不保存用户输入；
- ❌ 不采集、不上传、零遥测、无远程代码。

**权限说明**：只申请 `activeTab`、`scripting`、`sidePanel`、`storage`、`contextMenus` 五项；
**未点击扩展图标前，不向任何页面注入任何脚本**。详见 `docs/隐私声明.md`。

**局限**：判定是**启发式**的，结论是"观察到了什么 + 命中了哪条规则"，**不是**对站点的事实认定或法律意见；
基准是**合成基准**（自建 40 页 fixture），不是真实站点统计。

## 3. 生成方式（产物一律生成，禁手编）

```bash
npm run store:icons         # 生成 assets/store/ 的 4 枚图标（确定性 PNG 编码器）
npm run store:icons:check   # 重生成与盘上产物逐字节比对
npm run store:screenshots   # 用真实浏览器渲染产出 2 张商店截图（缺浏览器时显式 SKIP）
```

- **图标**：`tools/gen-store-icons.mjs` 用自写最小 PNG 编码器（`node:zlib` deflate + 自算 CRC32）**确定性**产出；
  图形是深蓝圆底 + 白色放大镜 + 镜内三条证据线，用归一化坐标解析式光栅化（无随机、无字体依赖、无外链）。
- **截图**：`tools/smoke-export.mjs --shots` 在**真实浏览器**里渲染后 `Page.captureScreenshot` 产出。
  截图是真实渲染产物，**不做逐字节断言**（浏览器渲染逐次有像素级差异）——只断言存在与尺寸。

> **脱敏**：所有素材与截图只含**合成 fixture**（假站点名"示例商城（虚构）"、域名 `example.invalid`），
> 不含任何真实站点、真实商品或个人信息。
