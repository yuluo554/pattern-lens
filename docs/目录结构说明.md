# 目录结构说明 · 界面取证镜（pattern-lens）

> `plan/01` §三 第 2 项要求"`src/` 附 `docs/目录结构说明.md`"。本文件说明仓库的**目录职责**与
> **哪些进安装包、哪些不进**。口径单点在 `tools/build-extension.mjs` 的 `RUNTIME_WHITELIST` /
> `BUNDLED_ONLY_DIRS`，本文件只做说明，不定义第二份清单。

## 顶层

| 目录 / 文件 | 职责 | 进安装包？ |
| --- | --- | --- |
| `manifest.json` | MV3 清单（权限白名单、`action`、`sidePanel`、`icons`；**无 `content_scripts`**） | ✅ |
| `src/` | 扩展源码（见下） | 部分（见白名单） |

| `data/` | 合成 fixture（40 页 + 逐页真值 + 覆盖矩阵 + 5k 压力页）与数据口径台账 `data/README.md` | ❌ |
| `tests/` | `node --test` 套件（门与判据；逐文件登记在 `package.json` 的 `scripts.test`） | ❌ |
| `tools/` | 自写工具：拼接器、构建、fixture 生成、基准、布局门、发布门、浏览器冒烟、图标生成 | ❌ |
| `docs/` | 目录结构说明（本文件）、隐私声明、商店素材清单 | ❌ |
| `assets/store/` | 商店素材**实物**（图标 PNG + 商店截图），与 `docs/商店素材清单.md` 逐项对账 | ✅（图标） |
| `plan/` | 项目计划套件 `00`–`07` + 交接单 `HANDOFF-M*.md` + 发布留档 `RELEASE-M6.md` | ❌ |
| `dist/` | `npm run build` 产物：可 Load unpacked 的扩展树（**不进 git**） | —（构建产物） |
| `release/` | 确定性 zip（M6 的 Release 附件；**不进 git**） | —（构建产物） |

## 进安装包 / 不进安装包的口径

- **进**（`RUNTIME_WHITELIST`）：`manifest.json` + `scanner.js`（拼接产物）+ 4 枚图标 + `src/background/**` + 除 `src/content/**` 外的 `src/lib/**` + `src/sidepanel/**`。
- **不进**（`BUNDLED_ONLY_DIRS`）：`src/content/**` —— 它已被 `tools/bundle.mjs` 拼进 `scanner.js`（content script 不能静态 import ESM）。
- **一律不进 dist**：`plan/`、`data/`、`tests/`、`tools/`、`docs/`。
- 新增 `src/lib` 文件必须**同时**登记进 `RUNTIME_WHITELIST`（`tests/build.test.mjs` 会核对，别指望"自动"）。
