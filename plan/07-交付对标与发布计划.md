## 三、M6 发布执行清单（按真实动作序列设计）

### 3.1 tag 前（全部完成才允许建 tag）

1. [ ] `plan/06` §二 各 DoD 逐项有证据；`plan/00` §5、`plan/06` §一、`README.md` 状态行**三处一致**（布局门绿）
2. [ ] `npm run verify --strict` rc=0（**未启用段必须清零**）；`npm run build` 产出 `dist/` + zip，且 `--check` 双跑逐字节一致
3. [ ] 脱敏四步：① 关键词扫描（账号名 / 本机盘符 / 邮箱 / 真实站点域名）；② 提交身份与 tagger 邮箱为 noreply；
       ③ `.gitattributes` 检查（文本归一 + 需冻结字节的文件标 `-text`）；④ 产物扫描（dist 与 zip 内无本机路径）
4. [ ] 干净环境验证：`git clone --no-local <repo> <中立目录>` → 不装包 → `npm test` + `npm run verify` + `npm run build` 逐条跑通
5. [ ] `plan/RELEASE-M6.md` **在 tag 之前写好并入库**（两栏 + 覆盖对账表三态逐条；
       **包内只写复验方法，不写附件哈希**——写入动作会改变包内容）
6. [ ] 建仓：`gh repo create yuluo554/pattern-lens --public --source . --remote origin`（**仓库名待用户拍板**，见 §四 Q1）

### 3.2 tag 与 Release

7. [ ] annotated tag：`git tag -a v0.1.0 -m "..."` → 核对 tag 对象两端一致（本地 `cat-file` == 远端 `git/ref/tags/v0.1.0` 的 `object.sha`）
8. [ ] `git push origin main` → 等 CI 全绿（**push 数 = run 数**逐条配对；branch run 与 tag run 两条都要绿）
9. [ ] `gh release create v0.1.0 <zip> --notes-file <C:/路径>`（`gh` 不认 `/tmp/...`）→
       `gh release view --json isDraft,assets` 确认；**sha256 写入 Release 正文**（不动仓库树）
10. [ ] 真下载复核：`gh release download` → `sha256sum -c` 对留档件 → 从 tag 树重建产物与之 `cmp` **逐字节一致**

### 3.3 tag 后（只允许文档面追加）

11. [ ] tag 后只有追加类提交（`git log --oneline v0.1.0..HEAD` 可逐条核对，提交信息用"追加/补记/对账"语义词）
12. [ ] `git diff --name-only v0.1.0..HEAD` 只含 `plan/`、`README.md`
13. [ ] `plan/RELEASE-M6.md` §二 回填真实事实（run id / 下载 sha256 / 复核结论）——**追加事实，不覆盖原措辞**

### 3.4 阶段 7 出口门覆盖对账（写进 `plan/RELEASE-M6.md`）

`plan/01` 与 skill 阶段 7 的每条出口门，必须在留档里给一个归宿，**三态不许留空**：

| 出口门 | 归宿 | 依据 |
| --- | --- | --- |
| 发布物本体已验（真下载 + 中立目录） | 实现 | 3.2 第 10 条 |

| 源码包自足（`MANIFEST.in`） | **不适用** | 本项目不发行 Python 源码包；附件 = 扩展 zip |

| 多平台冻结产物原生构建 | **不适用** | 无跨平台编译产物；zip 由 Node 生成且跨平台重生成逐字节一致 |
| 每条已交付命令一条离线 CI 冒烟 | 实现 | CI 逐步骤 = `layout / test / verify / build` |
| 发布门可复跑（离线 + `--online` + `--pre-tag`） | 实现 | `tools/check-release.mjs` 三模 |
| 离线模式报 SKIP 不报 PASS | 实现 | 门自身断言 |

| annotated tag 两端一致 = 对象哈希一致 | 实现 | 3.2 第 7 条 |
| tag 之后只允许文档面提交 | 实现 | 3.3 第 12 条 |

| 干净环境按 README 逐条跑通 | 实现 | 3.1 第 4 条 |
