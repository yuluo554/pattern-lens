# 03 · 架构与技术选型

> 状态：M0 已落地骨架（2026-10-18）。本文档只记录**实际存在**的结构；未实现的能力在 `plan/06` 列 ⬜。

## 一、形态与硬约束

| 项 | 决定 | 落地方式 |
| --- | --- | --- |
| 交付形态 | Chrome/Edge **Manifest V3 扩展**（唯一形态） | `manifest.json` + `src/`，`npm run build` 产出可 `Load unpacked` 的 `dist/` 树 + 确定性 zip |
| 后端 / 模型 | 无 | 全部判定在扩展内完成（页面内采集 + 纯函数判定核心） |
| 框架 / 打包器 | 无 | 原生 ESM（扩展页）+ 一步自写拼接（content script，见 D14） |
| 第三方依赖 | 零（`dependencies` 与 `devDependencies` 均为空） | `git clone` 后无需 `npm install` 即可 `npm test` |
| 外链 | 零 | 源码与产物静态扫描 `http(s)://` 计数为 0；字体用系统栈 |
| 美术资源 | 仅图标（M5 落 `assets/store/`） | 无位图素材依赖 |
| 数据 | 自带合成 fixture（40 页） | `data/fixtures/` + `data/fixtures/truth/`，由 `tools/gen-fixtures.mjs` 程序化生成 |
| 隐私 | 零采集 / 零上传 / 零遥测 | 源码断言无 `fetch`/`XHR`/`sendBeacon`；结果只落本机 storage |

## 二、分层

```
manifest.json                  MV3 清单：权限白名单、action、sidePanel、无 content_scripts
src/background/service-worker.js  只做两件事：action 点击 → 开 sidePanel；收到"开始扫描" → 站点开关检查 → executeScript 注入
src/content/collector.js      页面内采集：渲染后 DOM → 归一化 PageModel（文本/属性/样式子集/几何）；**只读**
src/content/scanner.js        注入入口：collect → matchRules → runtime.sendMessage(ScanResult)；超时 → 部分结果 + truncated
src/lib/page-model.js         PageModel 形状与工具（节点定位串、文本节点枚举、证据取值）
src/lib/rules.js              规则包加载/校验（字段、枚举、匹配优先级；缺字段拒绝加载）
src/lib/engine.js             判定核心（纯函数）：matchRules(model, pack, options) → {findings, rejected}
src/lib/ordering.js           排序与编号（severity 降序 → DOM 文档序 → 稳定编号）
src/lib/serialize.js          唯一写盘/序列化点（JSON 字段顺序、LF、结尾换行）——导出与基准共用
src/lib/export.js             证据包导出（Markdown / JSON，字段顺序固定，不含截图）
src/lib/rng.js                确定性 RNG（splitmix64）——fixture 生成与冒烟造数用，禁 stdlib random
src/ui/copy.js                可见文案单点（"可疑模式（待核对）"、空结果文案、分组名、禁用词表）
src/sidepanel/index.html      侧边栏骨架（四组分组容器 + 导出/设置入口）
src/sidepanel/sidepanel.js    侧边栏交互：渲染 findings、双向联动、导出、规则开关、站点黑白名单
src/sidepanel/sidepanel.css   侧边栏样式（不注入宿主页面）
tools/bundle.mjs              依赖序拼接（自写，无第三方打包器）：src/lib + 规则包 + 采集器 → dist/scanner.js（经典脚本）
tools/build-extension.mjs     产出 dist/ 扩展树 + 确定性 zip（ZIP_STORED + 固定时间戳 + 固定条目序）
tools/gen-fixtures.mjs        生成 40 页 fixture + 真值（确定性，`--check` 再生成位级一致）
tools/hash-rules.mjs          重算规则包内容哈希 → 写回 rules/manifest.json
tools/verify.mjs              一条命令全量自检（分段，rc=0 全绿）
tools/check-sprint-layout.mjs 布局门（方法论装订第②件）
tools/check-release.mjs       发布终态自检（离线 / --online；刻意不进 CI）
tests/                        node --test 套件（见 plan/05 §五）
```

**依赖方向单向**：`ui/` → `sidepanel`/`engine`，`engine` → `lib/*`，`lib/*` **不 reverse import**。
`src/lib/**` 内**禁止相互 import**（拼接顺序由 `tools/bundle.mjs` 显式声明）——这是自写拼接能成立的前提，配 AST 守门。

## 三、消息与数据协议

| 消息 | 方向 | 载荷 | 说明 |
| --- | --- | --- | --- |
| `open-sidepanel` | action 点击 → SW | 无 | `chrome.sidePanel.open({ windowId })` |
| `start-scan` | sidePanel → SW | `{ tabId }` | SW 先查站点开关；命中黑名单回 `blocked-site`，不注入 |
| `scan-result` | content script → SW/sidePanel | `ScanResult` | SW 落 `chrome.storage.session` 的 `LastScan` 并转发侧边栏 |
| `apply-overlay` / `clear-overlay` | sidePanel → content script | `{ findings }` / 无 | M3 覆盖层注入与清除 |
| `focus-finding` | sidePanel ↔ content script | `{ finding_id }` | 双向联动（滚动/闪烁/条目高亮） |

数据结构（M0 已定稿，字段不改名；新增字段只能追加）：

```js
ScanResult = { url, scanned_at, node_count, elapsed_ms, truncated, ruleset_version, ruleset_hash, findings[], rejected[] }
Finding    = { finding_id, rule_id, rule_name, category, severity, snippet, snippet_truncated, locator, evidence[], explanation }
Rejected   = { rule_id, locator, missing_evidence[] }
RuleSpec   = { rule_id, name, category, severity, detect, evidence_required[], locator_strategy, explanation }
```

## 四、权限白名单（硬约束，进自动化断言）

| 权限 | 为什么需要 | 不申请的反例 |
| --- | --- | --- |
| `activeTab` | 用户点击后临时获得当前标签页授权 | 弃 `<all_urls>`（常驻全站读取） |
| `scripting` | `executeScript` 按需注入扫描器 | 弃 `content_scripts` 静态注入（未点击即注入） |
| `sidePanel` | 取证台宿主（Chrome 114+） | — |
| `storage` | `storage.session` 存扫描结果；`storage.local` 存设置 | 弃 `cookies`（不读登录态） |
| `contextMenus` | 右键菜单入口（FR-02） | 弃 `tabs`（不需要读全部标签页元数据） |

**断言**：`tests/permissions-whitelist.test.mjs` 逐项比对 `manifest.json` 的 `permissions` 集合等于上表集合，
`host_permissions` 为空（或不存在），且 `content_scripts` 键不存在。**白名单只此一份**（测试里引用同一常量文件）。

## 五、构建

| 步骤 | 命令 | 产出 | 确定性口径 |
| --- | --- | --- | --- |
| 拼接 content script | `node tools/bundle.mjs` | `dist/scanner.js`（经典 IIFE，规则包内联为字面量） | 依赖序显式声明 + 无时间戳 → 双跑逐字节一致 |
| 组装扩展树 | `node tools/build-extension.mjs` | `dist/{manifest.json, scanner.js, sidepanel/**, lib/**}` | 文件集合 = manifest 引用闭包（白名单口径） |
| 打 zip（发布附件） | `npm run build` | `pattern-lens-<version>.zip` | `ZIP_STORED` + `create_system=0` + 固定时间戳 `(1980,1,1,0,0,0)` + 条目按路径排序；**跨平台重生成逐字节一致**（配 `--check`） |

**为什么 zip 要这样打**（`plan/05` 的确定性纪律）：zip 的 "version made by" 字节随生成平台变、deflate 流随 zlib 版本漂移，
Windows 上生成、ubuntu CI 上重生成会全挂。故一律 `ZIP_STORED` + 常量 `create_system` + 固定时间戳。
**自写 zip 写入器**（~80 行：local header + central directory + CRC32），不引第三方包。

**不进 dist 的东西**：`plan/`、`data/`、`tests/`、`tools/`、`docs/`、`src/content/`（已被拼接进 `scanner.js`）。
**安装面白名单**（`RUNTIME_WHITELIST`，`tools/build-extension.mjs` 单点定义）= `manifest.json` + `scanner.js`
+ `src/background/service-worker.js` + `src/lib/*.js`（全部）+ `src/sidepanel/{index.html,sidepanel.js,sidepanel.css}`。
新增 `src/lib` 文件**必须**同步登记，否则 `tests/build.test.mjs` 报红（安装面不许静默漂移）。

## 六、测试与基准策略（D15 的落地）

| 层 | 在哪跑 | 覆盖什么 | 缺件时的行为 |
| --- | --- | --- | --- |
| 判定核心单测 | Node `node --test` | 规则匹配、证据门禁、排序、导出、序列化、规则包 schema | 无缺件路径 |
| 规则基准（precision/recall） | Node，离线 | 40 页 fixture × 12 规则，门槛读 `rules/manifest.json` | 缺 fixture → **FAIL**（不是 SKIP） |
| 布局门 / 源码卫生 | Node，离线 | 方法论布局、禁用词、零外链、零网络 API、只读纪律、安装面白名单 | 无缺件路径 |
| CI 工作流静态自查 | Node，离线 | 步骤 name 无裸 `: `（会让 GitHub 不建 job）、必需步骤与顺序、矩阵声明 | 无缺件路径 |
| 浏览器冒烟（可选） | 本机有 Chromium 时 | 真实渲染路径：计算样式、注入时序、覆盖层、双向联动、resource 计数 | 缺浏览器 → **SKIP 并显式打印**，不得静默通过，也不得据此打 ✅ |

**承认的缺口（写进 README 局限披露）**：Node 侧基准的页面模型由**自写的轻量 HTML 解析器 + 声明的样式子集**
产出（inline style 与 fixture 生成器同步产出的 `style-map.json`），**不是浏览器计算样式**。
因此"隐形关闭"这类依赖计算样式的规则，其基准证明的是"判定核心在该模型下正确"，
真实渲染路径由浏览器冒烟补证（缺浏览器时该缺口如实标注，不冒充已验）。

## 七、编码纪律

- **只读宿主页面**：不写宿主样式（样式全在 Shadow DOM 内）、不改宿主属性、不插 `<style>` 到 `document.head`、不自动点击。
- **零时钟依赖**：判定核心不读时钟（`scanned_at` 只在采集入口取一次，不参与排序）；基准不读时钟。
- **零随机**：fixture 生成用 `src/lib/rng.js`（splitmix64，固定 seed），禁用 stdlib `Math.random`。
- **确定性写盘**：所有产物经 `src/lib/serialize.js`；JSON `JSON.stringify(obj, keyOrder, 2)` + LF + 结尾换行。
- **数值只在 `rules/manifest.json`**：阈值/枚举/优先级不得在 `src/`、`rules/dp-*.json`、文档里出现第二份（配门禁扫描）。
- **文案只在 `src/ui/copy.js`**：禁用词与固定文案单点定义，扫描器读它。
