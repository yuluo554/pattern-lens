# 02 · 需求解读与能力转译

> 上游 = `plan/01-题目文档.md`（题面，不改写）。本文档只做两件事：把痛点翻成**可判定的能力**，
> 把能力钉成**带优先级的 FR**，并写清**不做什么**（边界与非目标）。

## 四、边界与非目标（防 scope 失控）

- **不做打分 / 不做评级**：不产出"暗黑模式分数""欺诈指数"；只产出逐条证据与规则解释。
- **不做自动点击 / 不代用户取消订阅 / 不自动填表**：不代替用户操作，不绕过任何流程。
- **不做页面内容存档**：不截图、不存整页 HTML、不保存用户输入。
- **不做 ML 识别**：所有结论必须由可读规则与证据节点支撑，规则可逐条开关、可审计。
- **不申请宽泛权限**：`<all_urls>` / `tabs` / `cookies` / `webRequest` / `history` / `clipboardRead` / `downloads` 一律不申请。
- **隐私红线**：不采集、不上传、零遥测；不读取登录态；结果只存本机 `storage.session` / `storage.local`。
- **文案红线**：统一"可疑模式（待核对）"，不写"欺诈""违法""恶意网站"；每条结论附规则解释与原文。
- **品牌隔离**：不提名、不复用本系列其他项目的代码与业务描述。
- **首期范围**：12 条规则，不做全量分类学；规则包热更新、多语言、PDF 导出为 roadmap。
- **不宣称"全球首创"**：只写"公开仓库检索未见 ≥50★ 的成熟同类扩展"（软论据，检索式与基准日见 `data/README.md` §1.2）。
- **商业侧不得断言**：Chrome 应用商店在本机基准日不可达（`data/README.md` §1.3），任何"商店里没人做"的表述禁止。

## 五、受众与使用场景

| 受众 | 场景 | 本工具给什么 |
| --- | --- | --- |
| 普通消费者 | 投诉/维权前留证 | 逐条可核对的证据包（Markdown，可粘贴进投诉信） |
| 隐私研究者 | 采集可复核样本 | 规则可审计 + 阈值单一真相源 + 可复现基准 |
| 记者 | 需要能引用的材料 | 原文片段 + 元素定位 + 扫描时间戳 |
| 测评自媒体 | 批量替代截图 | JSON 证据包（可程序化汇总），不用截图取证 |
